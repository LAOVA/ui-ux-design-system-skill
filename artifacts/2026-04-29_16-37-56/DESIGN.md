# BMW M Forum Design System

## Overview

**Project Name:** BMW M Forum
**Category:** Automotive Community / Forum
**Summary:** 一个基于 BMW M 风格的高性能论坛界面。采用深色高级表面、精确的德国工程美学，以及标志性的 M 系列色彩。

## Visual Direction

- **Style:** AI-Native UI (General) - 结合了豪华汽车的质感。
- **Mood:** 专业、高性能、工程感、高端。
- **Key Effects:** 打字指示器（3点脉冲）、流式文本动画、脉冲动画、上下文卡片、平滑揭示。

## Color Palette

- **Primary:** `#1c69d4` (BMW Blue) - 用于主按钮和品牌元素。
- **Secondary:** `#0066b1` (M Blue Light) - 用于次要品牌元素。
- **Accent:** `#e22718` (M Red) - 用于警示、强调和高性能指示。
- **Background:** `#1a2129` (Surface Dark) - 主背景色。
- **Foreground:** `#ffffff` - 主文本颜色。
- **Muted:** `#262e38` (Surface Dark Elevated) - 卡片和次要背景。
- **Border:** `#e6e6e6` - 用于精细的线条。

## Typography

- **Heading:** BMW Type Next Latin (700) - 粗重、有力的显示字体。
- **Body:** BMW Type Next Latin (300) - 轻量、清晰的正文字体。
- **Mood:** 这种字体组合传达了 BMW 企业形象的稳重感，同时又不失 M 系列的爆发力。

## Layout and Flow

1. **Hero:** 社区价值主张，展示高性能汽车和活跃讨论。
2. **Popular Topics:** 热门话题和分类，采用品牌色的标签。
3. **Active Members:** 活跃成员展示，增加社区的人文感。
4. **Join CTA:** 醒目的加入按钮。

## Implementation Guidance

- **Buttons:** 采用圆角（2xl）和深色背景，配合 BMW Blue 或 M Red 的悬停效果。
- **Cards:** 使用 `Surface Dark Elevated` 背景，配合细微的边框。
- **Spacing:** 采用严谨的间距系统，确保界面的工程感和精确度。

## Anti-Patterns

- 避免过度装饰。
- 避免低对比度，确保在深色背景下的可读性。
- 不要混合非 BMW M 系列的色彩。
