# BMW-M CMS 设计系统

这是一个基于 BMW M 系列高性能赛车美学设计的内容管理系统 (CMS) 界面规范。它结合了德国精密工程感、碳纤维纹理以及经典的 M 系列色彩。

## 视觉导向
- **核心气质**: 极致性能、精密感、高对比度、科技感
- **风格**: 黑暗模式 (OLED 优化)，采用碳纤维纹理和深蓝色调作为背景。

## 色彩规范 (M-Colors)
| 角色 | 颜色值 | 描述 |
| :--- | :--- | :--- |
| **Primary (M Blue Dark)** | `#1c69d4` | 主品牌色，用于主要按钮和激活状态 |
| **Secondary (M Blue Light)** | `#0066b1` | 辅助品牌色，用于次要标识和悬浮效果 |
| **Accent (M Red)** | `#e22718` | 强调色，用于警告、错误或高性能指标 |
| **Background (Deep Navy)** | `#1a2129` | 主背景色，模拟高级内饰基调 |
| **Surface (Carbon)** | `#262e38` | 卡片和容器背景，建议配合微弱的碳纤维纹理 |
| **Foreground (White)** | `#ffffff` | 主要文字颜色 |
| **Muted** | `#bbbbbb` | 次要文字和装饰线条 |

## 字体规范
- **标题**: `BMW Type Next Latin` ( fallback: `Inter`, `system-ui` )
- **正文**: `Inter`
- **特征**: 粗体标题 (700)，细体正文 (300/400)，高字间距，强调力量感。

## UI 组件特征
- **边框**: 极细边框 (`1px`)，颜色为 `rgba(255,255,255,0.08)`。
- **圆角**: 锐利或极小圆角 (`2px - 4px`)，体现机械切削感。
- **特效**: 
  - 微弱的发光效果 (Glow) 用于活动状态。
  - 碳纤维纹理叠加 (Carbon Fiber Texture)。
  - 渐变色用于模拟金属拉丝感。

## 布局模式
- **Bento Grid**: 仪表盘采用 Bento 布局，高信息密度。
- **Side Navigation**: 极简侧边栏，仅保留核心功能图标，悬浮展开。

## 反模式 (应避免)
- 使用圆润的、糖果色的设计。
- 低对比度的灰度方案。
- 过度装饰的阴影（应使用发光或描边代替）。
