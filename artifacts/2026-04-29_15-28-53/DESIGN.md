# X.AI Info Platform 设计系统规范

本规范定义了 X.AI 风格资讯平台的核心视觉语言、交互原则及实现细节。该系统深受 x.ai (Grok) 的启发，强调高对比度、极简主义和技术化的蓝图美学。

## 1. 核心理念

- **极致极简 (Exaggerated Minimalism)**: 消除一切非必要的装饰，让信息本身成为焦点。
- **高对比度 (High Contrast)**: 采用纯黑背景与纯白文字，确保极致的清晰度与品牌力度。
- **技术蓝图感 (Technical Blueprint)**: 通过精细的边框、等宽字体细节和结构化的布局（如 Bento Grid）传达专业性。
- **信息密度 (Information Density)**: 在保持呼吸感的同时，通过紧凑的排版展示大量高价值数据。

## 2. 视觉语言

### 2.1 色彩调色板 (Color Palette)

| 标记 (Token) | 颜色值 (Hex) | 用途 (Usage) |
| :--- | :--- | :--- |
| `background` | `#000000` | 页面背景，深邃且专注 |
| `foreground` | `#FFFFFF` | 主要文字、主要图标 |
| `primary` | `#FFFFFF` | 强调色，主要用于 CTA 和高亮 |
| `secondary` | `#A3A3A3` | 次要文字、说明性内容 |
| `muted` | `#262626` | 背景块、装饰性边框 |
| `border` | `#3F3F46` | 分隔线、组件描边 |
| `accent` | `#1D9BF0` | 极少数交互状态（如链接、激活态） |

### 2.2 字体系统 (Typography)

- **标题 (Heading)**: `Inter`, sans-serif. 采用 900 字重，-0.05em 字间距，产生压倒性的视觉冲击力。
- **正文 (Body)**: `Inter`, sans-serif. 400 字重，高可读性。
- **技术细节 (Mono)**: `JetBrains Mono`, monospace. 用于数据展示、代码片段或元信息，增强技术感。

### 2.3 布局与空间 (Layout & Space)

- **Bento Grid**: 核心功能与特性展示采用不等宽的网格布局。
- **呼吸感**: 保持充足的内边距 (Padding) 和外边距 (Margin)，即便在信息密集的区域。
- **圆角 (Radius)**: 采用大圆角 (`24px` 或 `32px`) 来平衡高对比度带来的尖锐感。

## 3. 组件准则

### 3.1 按钮 (Buttons)

- **Primary**: 纯白背景，纯黑文字。Hover 时略微透明。
- **Secondary**: 描边模式（1px #3F3F46），纯白文字。

### 3.2 卡片 (Cards)

- 背景色采用深灰色 (`#0A0A0A`) 或带模糊的玻璃拟态。
- 极细的描边 (`1px border`)。

## 4. 交互原则

- **响应式**: 移动端优先，在小屏幕上采用垂直堆叠布局。
- **动效**: 极简的淡入淡出 (Fade) 和轻微的缩放 (Scale)，避免复杂的动画。
- **无障碍**: 确保文字对比度符合 WCAG AA 标准（黑色背景上的白色文字天生具备极高对比度）。
